# Security Policy

## Supported Versions
We aim to support the latest stable Flutter and major release of this app.

## Reporting a Vulnerability
If you discover a security issue:
1. DO NOT open a public issue describing exploit details.
2. Email: `security@example.com` (replace with a real contact)
3. Include: affected version, reproduction steps, potential impact.
4. Expect initial acknowledgement within 72 hours.

## Scope
- Data leakage (guardian info, locations, face images)
- Unauthorized SOS trigger or escalation abuse
- Injection attacks via external inputs
- Model integrity (tampered TFLite file)

## Handling Process
1. Triage & reproduce
2. Assign CVSS-like severity
3. Prepare patch & regression tests
4. Issue security advisory and release patched version

## Responsible Disclosure
We appreciate coordinated disclosure and will credit reporters where permitted.
