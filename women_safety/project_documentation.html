🏗️Architecture & Design Patterns

State Management

  • BLoC Pattern: Auth, Theme, Location, and SOS state management
  • Cubits: Lightweight state management for specific features
  • Provider: Dependency injection and service access

Service Layer Architecture

┌─────────────────────────────────────────────────────────┐ │ Presentation Layer │ │ (Screens, Widgets, BLoC/Cubits) │ └───────────────────┬─────────────────────────────────────┘ │ ┌───────────────────▼─────────────────────────────────────┐ │ Service Layer │ │ • SOS Service (Orchestrator) │ │ • Location Share Service │ │ • WhatsApp/SMS Services │ │ • AI Services (Danger, Voice, Face) │ │ • Protection & Guardian Services │ │ • Notification & Offline Queue │ └───────────────────┬─────────────────────────────────────┘ │ ┌───────────────────▼─────────────────────────────────────┐ │ Data Layer │ │ • Firebase Firestore │ │ • Local Storage (SharedPreferences, SQLite) │ │ • Remote APIs (Agora, Google Maps) │ └─────────────────────────────────────────────────────────┘

Key Design Principles

Modular Services

Each feature is isolated in its own service class for maintainability

Fail-Safe Mechanisms

Multiple fallback options for critical operations (SMS schemes, offline queue)

Offline-First

Queue system for alerts when network is unavailable

Security

No hardcoded credentials, encrypted evidence storage

🔧Setup & Configuration Guide

Prerequisites

  • Flutter SDK 3.9 or higher
  • Android Studio / VS Code
  • Firebase Account
  • Android Device with USB Debugging enabled

Installation Steps

# 1. Clone repository git clone <repo-url> cd women_safety # 2. Install dependencies flutter pub get # 3. Configure Firebase # Add android/app/google-services.json # Add ios/Runner/GoogleService-Info.plist # 4. Run on device flutter run # 5. Build release APK flutter build apk --release

Configuration Checklist

Integration Required Action Priority
Firebase Add google-services.json to android/app/ Critical
Agora Replace YOUR_AGORA_APP_ID in live_streaming_service.dart Optional
TFLite Model Add danger_prediction_model.tflite to assets/models/ Optional
Permissions Grant location, camera, microphone, notifications Critical

Environment Variables (Optional)

# Create .env file (not in version control) AGORA_APP_ID=your_agora_app_id FIREBASE_API_KEY=your_firebase_key GOOGLE_MAPS_API_KEY=your_maps_key

ADB Installation & Testing

# Install via winget (Windows) winget install --id Google.AndroidSDK.PlatformTools # Verify device connection adb devices # Install APK adb install -r build/app/outputs/flutter-apk/app-release.apk # View logs adb logcat | Select-String -Pattern "Flutter|women_safety"

Common Issues & Solutions

Firebase Not Initialized

Solution: Add google-services.json to android/app/ and rebuild

WhatsApp Not Opening

Solution: Ensure WhatsApp installed, check phone numbers have country code

Location Not Working

Solution: Grant location permissions in Settings → Apps → Women Safety

Widget Not Visible

Solution: Some launchers hide widgets, try different launcher or check manifest

Debug Commands

# Run in debug mode with hot reload flutter run -d android # Check for build errors flutter analyze # Clear cache and rebuild flutter clean flutter pub get flutter build apk --release # View device logs filtered adb logcat -v time | Select-String "Flutter|Dart|women_safety" # Check Firebase connection adb logcat | Select-String "Firebase" # Monitor widget updates adb logcat | Select-String "PanicWidget|home_widget"
