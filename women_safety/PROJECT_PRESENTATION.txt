WOMEN SAFETY APP - PROJECT PRESENTATION

ABSTRACT
Women safety is a critical concern in modern society, especially during travel, late hours, and isolated situations. This project presents a smart women safety mobile application designed to deliver rapid emergency assistance through an intelligent and user-friendly platform. The app provides a one-tap SOS flow and a home-screen panic widget for instant emergency activation. Once triggered, it sends multi-channel alerts to guardians through SMS and push notifications, shares real-time location via Google Maps links, and supports continuous tracking during active SOS sessions.

The system also includes AI-assisted safety capabilities such as danger prediction, voice distress analysis, and safe journey or route monitoring. During emergencies, the application can capture supporting evidence, including photos, audio, and video, and offers fake call assistance for high-risk social situations. Built with Flutter and Firebase, with native Android widget integration using Kotlin, the solution focuses on fast response, reliability, and accessibility under stress. By combining automation, intelligent monitoring, and guardian-based support in one platform, this project aims to improve personal safety outcomes and confidence in real-world emergencies.

1) PROJECT TITLE
Women Safety App: AI-Powered Emergency Protection Platform

2) PROBLEM STATEMENT
Personal safety emergencies often require immediate action, but users may not be able to unlock phones, type messages, or call for help in time.
Current safety workflows are slow, manual, and fragmented.

3) SOLUTION OVERVIEW
The Women Safety App provides fast emergency response through one-tap and automatic triggers.
It combines SOS alerts, guardian communication, location sharing, call escalation, and AI-assisted safety features into a single mobile platform.

4) CORE OBJECTIVES
- Trigger emergency support in seconds
- Automatically notify trusted guardians with live location
- Reduce dependency on manual actions during panic situations
- Provide intelligent safety tools beyond basic SOS

5) KEY FEATURES
A) SOS and Emergency Communication
- One-tap SOS trigger
- Automatic SMS alerts to guardians
- Location sharing during emergency
- Alarm activation for nearby attention
- Emergency call support

B) Advanced Safety Features
1. Fake Call Assistance
2. Panic Widget Trigger
3. Live Streaming Support
4. Ride Tracking
5. Guardian Network
6. Face Recognition Support
7. Voice Distress Analysis (keyword and distress detection)
8. AI Danger Prediction

C) Reliability and Protection Layers
- Background/global SOS listeners
- Offline queue for pending actions
- Call escalation across multiple guardians
- Notification integration for critical events

6) TECH STACK
- Frontend: Flutter (Dart)
- Backend/Cloud: Firebase services
- State Management: Bloc/Cubit
- Device Services: GPS, microphone, notifications, SMS/call integration
- Android tooling: Gradle + Flutter build pipeline

7) HIGH-LEVEL ARCHITECTURE
- UI Layer: Screens for home, SOS, profile, map, settings, and advanced features
- Business Logic Layer: Cubits and service classes for authentication, SOS flow, and AI features
- Data Layer: Firestore user/guardian records and cloud-backed app state
- Integration Layer: Phone, SMS, location, notification, voice, and safety monitoring services

8) RECENT IMPROVEMENTS IMPLEMENTED
- Voice distress keyword detection strengthened for better SOS triggering
- Foreground voice analysis flow now triggers SOS more reliably
- Startup loading time reduced with faster auth initialization and splash fallback timeout
- Stability improvements around error handling in SOS voice flow

9) USER FLOW (DEMO SCRIPT)
1. User opens app and logs in
2. User configures guardians
3. User enables voice distress analysis
4. User speaks distress phrase (example: help me)
5. App detects distress and triggers SOS
6. Guardians receive emergency alert and location updates
7. Call escalation begins if required
