FLUTTER UNIT TESTS - ONE COMMAND
================================================================================

Run all unit tests:
  $ flutter test

Run with verbose output:
  $ flutter test -v

Run specific test file:
  $ flutter test test/unit/sos_trigger_test.dart

Run specific test method:
  $ flutter test -k "Manual SOS Button Click"

Run with code coverage:
  $ flutter test --coverage
  $ genhtml coverage/lcov.info -o coverage/HTML

Run continuously (watch mode):
  $ flutter test --watch

Run with timeout override (in milliseconds):
  $ flutter test --timeout 60000

Expected Output:
  ✅ Manual SOS Button Click Should Trigger SOS (1234ms)
  ✅ SOS Trigger Should Fetch Emergency Contacts (567ms)
  [SUCCESS] All 40+ tests passed in 45 seconds

================================================================================
REAL DEVICE TESTING VIA USB DEBUGGING
================================================================================

STEP 1: SETUP (One-Time)
  
  1. Enable USB Debugging:
     Device Settings → Developer options → USB Debugging → ON
  
  2. Connect device via USB cable
  
  3. Verify connection:
     $ adb devices
     ABC123XYZ          device

STEP 2: BUILD & INSTALL
  
  $ cd women_safety
  $ flutter build apk --release
  $ adb install build/app/outputs/flutter-apk/app-release.apk

STEP 3: LAUNCH APP
  
  Option A - Launch with Flutter:
    $ flutter run -d <device_id>
  
  Option B - Manual launch:
    $ adb shell am start -n "com.womensafety.app/.MainActivity"
  
  Option C - Tap app icon on device

STEP 4: VIEW LOGS IN REAL-TIME
  
  All logs:
    $ adb logcat
  
  Filter by SOS:
    $ adb logcat | findstr "SOS"
  
  Filter by Location:
    $ adb logcat | findstr "Location"
  
  Filter by Error:
    $ adb logcat | findstr "ERROR"
  
  Save to file:
    $ adb logcat > mylog.txt

STEP 5: TEST MANUALLY
  
  On device:
    1. App opens automatically
    2. Login: testuser@womensafety.com / Test@123456
    3. Add guardian: John Doe, +919123456789
    4. Tap SOS button
    5. Observe: Red pulsing indicator, contacts list, location prompt
    6. Wait 5 seconds for notifications
    7. Tap "Cancel SOS"
  
  In terminal:
    $ adb logcat | grep -E "🚨|📍|📲|✅|❌"

STEP 6: AUTOMATED TEST SCRIPT
  
  Run full device test suite:
    $ ./device_testing.sh
  
  Or on Windows PowerShell:
    $ powershell -ExecutionPolicy Bypass -File DEVICE_TESTING_WINDOWS.ps1

KEY COMMANDS BY CATEGORY

DEVICE MANAGEMENT
─────────────────
List devices:
  adb devices -l

Get device info:
  adb -s <device_id> shell getprop ro.product.model
  adb -s <device_id> shell getprop ro.build.version.release

Clear app data:
  adb -s <device_id> shell pm clear com.womensafety.app

Force stop app:
  adb -s <device_id> shell am force-stop com.womensafety.app

Reboot device:
  adb -s <device_id> reboot

Get device logs (pull to computer):
  adb -s <device_id> pull /data/data/com.womensafety.app/files/ ./app_files/

LOGGING & DEBUGGING
───────────────────
Clear logcat:
  adb logcat -c

View logs with timestamp:
  adb logcat -v time

Filter for app package:
  adb logcat WomenSafety:V

Increase logcat buffer:
  adb logcat -G 16M

Save live logs to file:
  adb logcat > logs/live_$(date +%s).log

View specific tags:
  adb logcat | grep "SOS_TRIGGER\|LOCATION_SERVICE\|NOTIFICATION"

NETWORK TESTING
───────────────
Test with slow network (emulator):
  Android Studio → Extended Controls → Network → Throttle

Disable WiFi:
  adb shell svc wifi disable

Enable WiFi:
  adb shell svc wifi enable

Simulate offline:
  adb shell svc data disable && adb shell svc wifi disable

Restore network:
  adb shell svc wifi enable && adb shell svc data enable

================================================================================
TROUBLESHOOTING QUICK FIXES
================================================================================

Device not showing in "adb devices":
  ✗ Solution: adb kill-server && adb start-server

Tests timeout:
  ✗ Solution: flutter test --timeout 60000

APK installation fails:
  ✗ Solution: adb shell pm clear com.womensafety.app && adb install -r app.apk

Firebase auth issues in tests:
  ✗ Solution: Mock Firebase - use mockito library

"No connected devices":
  ✗ Solution: Check USB cable, enable USB debugging, install ADB drivers

App crash during SOS:
  ✗ Solution: Check logs with adb logcat | grep ERROR

Tests pass locally but fail in CI:
  ✗ Solution: Mock timeouts, add waits, check environment variables
